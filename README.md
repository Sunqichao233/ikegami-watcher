# 池上自動車教習所 — 空位监视

一个油猴（Tampermonkey）脚本。挂在预约日历页上，自动在「次の週 / 前の週」之间来回翻页，
发现符合你条件的空き枠就立刻推送到手机。

---

## 一、安装

1. 浏览器装 [Tampermonkey](https://www.tampermonkey.net/)（Chrome / Edge / Firefox 都有）。

2. **打开「允许用户脚本」** —— Chrome 138+ 必做，否则脚本装了也不会运行：

   `chrome://extensions/`（Edge 是 `edge://extensions/`）→ Tampermonkey →「详细信息」→ 找到
   「**允许用户脚本 / ユーザー スクリプトを許可する**」，打开。

   旧版 Chrome 没有这个开关，改为在 `chrome://extensions/` **右上角**打开「**开发者模式**」。

3. 打开 Tampermonkey 面板 → **添加新脚本**（`+` 号）。

4. 把 [ikegami-watcher.user.js](ikegami-watcher.user.js) 的**全部内容**粘进编辑器，覆盖模板默认代码。

5. `Ctrl+S` 保存，然后回预约页 `Ctrl+F5` 硬刷新。

> 脚本只在 `https://www.e-license.jp/el32/pc/reserv/*` 生效。

> ⚠ **本地文件和油猴里的副本是两份独立的代码。** 油猴安装时把代码复制进了自己的存储，
> 之后不会再读这个仓库里的文件。改了本地文件必须**全选复制、去油猴编辑器整段覆盖粘贴**才生效。

## 二、配置推送（重要）

**必须在油猴编辑器里改脚本，改本地文件不生效。**

打开脚本 → 顶部 `CFG.notify` 区块 → 填上任意一个渠道的密钥，留空表示不启用，可以同时填多个。

```js
notify: {
    sound: true,        // 蜂鸣
    desktop: true,      // 桌面通知
    titleFlash: true,   // 标签页标题闪烁
    alertBox: false,    // 弹窗（会阻塞脚本，慎用）

    pushplus:   '',     // 微信
    serverchan: '',     // 微信
    wecom:      '',     // 企业微信群机器人
    bark:       '',     // iOS
    ntfy:       '',     // iOS / Android
    telegram:   '',
    discord:    '',
    webhook:    '',
},
```

各渠道密钥怎么拿：

| 渠道 | 填什么 | 哪里拿 |
|---|---|---|
| **Server酱³** | SendKey，形如 `sctp123t...` | <https://sct.ftqq.com> 微信扫码登录 |
| **PushPlus** | token | <https://www.pushplus.plus> 微信扫码登录 |
| **企业微信** | 群机器人 Webhook 地址 | 群设置 → 群机器人 → 添加 |
| **Bark**（iOS） | 形如 `https://api.day.app/xxxxx` | App Store 装 Bark，复制 App 里的 URL |
| **ntfy** | 形如 `https://ntfy.sh/你的topic` | 装 ntfy App，订阅一个自取的 topic |
| **Telegram** | `https://api.telegram.org/bot<TOKEN>/sendMessage?chat_id=<ID>` | BotFather |
| **Discord** | 频道 Webhook URL | 频道设置 → 整合 → Webhook |
| **webhook** | 任意 URL，收到 `POST {title, body, slots}` | 自建 |

Bark 还可以调提醒级别 `barkLevel`：`'active'` 普通 / `'timeSensitive'` 专注模式也响 / `'critical'` 静音也响。

### 翻页节奏（可选）

同在 `CFG` 里：

```js
sweepWeeks: 2,        // 2 = 本周 ↔ 下周来回；3 = 本周 → +1 → +2 → 折返
intervalMs: 60_000,   // 每次翻页间隔，建议 ≥ 30 秒
jitterMs:   15_000,   // 随机抖动 ±15 秒，避免固定节奏
```

## 三、使用

登录预约系统、进到**日历页**，右下角会出现黑色面板。

| 按钮 | 作用 |
|---|---|
| **▶ 开始 / ■ 停止** | 启停监控。状态存在 localStorage，翻页后自动续跑 |
| **⚙** | 可视化设置监控的星期 / 时段 / 特定日期区间 |
| **测试** | 向所有已启用渠道发一条测试消息，确认配置正确 |
| **现况** | 把当前这一周的完整空位情况推一份到手机 |
| **📋** | 复制全部日志到剪贴板 |
| **🗑** | 清空日志 |

**建议顺序**：先点「测试」确认手机能收到 → 点「⚙」设好想要的时段 → 点「▶ 开始」，然后这个标签页别关。

### ⚙ 设置窗

- **按星期**：7×12 的格子，横轴是时限（9:00 ~ 20:00），点一下切换。绿色 = 监控。
  下方有「全选 / 全清 / 平日夜间 19–20 / 周末全天 / 反选」快捷预设。
- **特定日期区间**：填一段日期（如暑假、连休），可指定时限或勾「全天」。
  **区间优先级高于星期表** —— 落在区间内的日子只按区间的规则判定。
- 设置存在 localStorage，改脚本里的 `weekdayZigen` / `fullDayRanges` 不会覆盖它；
  想回到脚本里的默认值，点「重置为默认」。

### 时限对照

| 限 | 时间 | 限 | 时间 |
|---|---|---|---|
| 1 | 9:00 | 7 | 15:00 |
| 2 | 10:00 | 8 | 16:00 |
| 3 | 11:00 | 9 | 17:00 |
| 4 | 12:00 | 10 | 18:00 |
| 5 | 13:00 | 11 | 19:00 |
| 6 | 14:00 | 12 | 20:00 |

## 四、说明

- 同一个空位只推送一次（按 `日期-时限` 去重），不会反复轰炸。
- 页面出现 **EC05 / 系统错误** 时会自动停止并蜂鸣，需要你手动处理后重新点「开始」。
- 日志跨页面保留最近 300 条，刷新不丢。
- 脚本只做**监控和通知**，不会自动帮你抢位 —— 收到通知后请自己去点。

## 五、面板不显示？

按这个顺序排查。

### 1. 「允许用户脚本」没开 —— 最常见

症状很有迷惑性：油猴弹窗里**能看到**脚本名、开关是**绿色**的，但页面上什么都没有，
控制台也**没有任何报错**。因为浏览器压根没让油猴注入代码。

按上面「安装」第 2 步打开开关，然后 `Ctrl+F5`。

### 2. 油猴里的代码不完整

粘贴时被截断了。进油猴编辑器拉到最底部，代码应该以 `})();` 结尾。
不对就全选删掉，重新粘一遍完整代码。

### 3. 改错了文件

在 VSCode 里改本地 `.user.js` 不会影响浏览器里跑的那一份。改动必须粘回油猴编辑器。

### 4. 确认脚本到底有没有跑

在油猴编辑器里，`'use strict';` 下面临时加一行：

```js
console.log('★IKG 已注入', location.href);
```

保存 → `Ctrl+F5` → F12 看控制台：

- **打印了** → 脚本在跑，那紧跟着一定有红色报错，按报错查。
- **没打印** → 还是没注入，回到第 1、2 条。

排查完记得把这行删掉。

### 5. 扩展的站点访问权限被限制

`chrome://extensions/` → Tampermonkey → 详细信息 → 「网站访问权限」若是「点击扩展程序时」，
改成「**在所有网站上**」。

### 顺手确认几件事

在预约页按 F12，控制台里跑：

```js
console.log(location.href, document.querySelectorAll('a.simei').length);
```

- URL 必须以 `https://www.e-license.jp/el32/pc/reserv/` 开头，否则 `@match` 不覆盖。
- 后面那个数字是本周空位数。日历里一个绿格子都没有时它就是 `0` —— **这是正常的**，
  不是脚本坏了，等它翻到有空位的周才会有命中。
